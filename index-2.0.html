Act 1

Possession is not the same as control

Story function

This opening view creates tension. If Barcelona can lose despite overwhelming possession, the audience immediately needs an explanation for where that control breaks down.

The boxplot shows that Barcelona still recorded very high possession in several matches they failed to win, especially away from home.

If possession alone does not secure results, the next question is whether Barcelona at least convert control into a steady attacking output.

Act 2

Scouting for hidden gems

Story function

This scouting view now uses only Barcelona players and shows all available seasons for the shortlisted under-25 profiles. Players are shortlisted from the ones whose short passing and vision improve over their latest three-season window, then their full Barcelona progression is shown in the chart.

Each player keeps one color across the chart, while solid lines show short passing and dashed lines show vision. The Plotly toolbar lets you zoom, reset axes, autoscale, and inspect the lines directly.

Once the most promising technical profiles are visible, the next step is to understand which opponents most consistently expose the team’s broader attacking weaknesses.

Act 3

Which opponents actually shut Barcelona down?

Story function

This heatmap shows how many goals Barcelona scored on average against each opponent in each season. Each row is one opponent, each column is one season, and each cell combines both the number and the color for the same value.

Lighter cells mean Barcelona scored fewer goals per match on average, so they point to harder attacking matchups. Darker cells mean Barcelona scored more freely. Because the values are averages, numbers like 1.50 or 3.50 appear when Barcelona played the same opponent more than once in a season.

To keep the view readable, the chart focuses on the 12 recurring opponents against whom Barcelona scored the least on average across the period. That makes the “kryptonite” pattern easier to see than if every team were included.

Only recurring opponents are considered, and the final heatmap keeps the 12 toughest ones by Barcelona’s average goal output. That smaller set is easier to read and better supports the storytelling goal.

Once the most difficult opponents are visible, the last question is whether this weakness is unusual or just part of how elite clubs perform against strong resistance.

Act 4

Where does Barcelona sit among Europe’s elite?

Story function

This final benchmark reconstructs season standings from match results, keeps only the five major leagues, and then selects the three strongest long-run representatives from each league for comparison with Barcelona.

Position shows possession and goals per match, while bubble size adds points per match. The comparison group is data-driven and restricted to the top 3 teams from each major league.

Conclusion

What the story suggests

The four acts point to a consistent message: Barcelona often control games territorially, but the most important competitive difference is whether that control becomes efficient attack against strong opponents.

1

Main finding

High possession is part of Barcelona’s identity, but it is not a guarantee of positive results by itself.

2

Main finding

The strongest seasons are the ones where shot volume, goal output, and accuracy rise together instead of relying on control alone.

3

Main finding

A small set of opponents consistently reduce Barcelona’s scoring output, which suggests specific matchup vulnerabilities rather than random fluctuation.

4

Recommendation

Future tactical analysis should focus less on possession totals alone and more on how quickly possession turns into shots, entries, and goals.

Build notes

How the page is assembled

The visuals are generated in Python and embedded here as HTML charts. Rebuild them after changing the datasets by running `'/Applications/anaconda3/bin/python' build_visualizations.py`.

1

Data source

`master_matches.csv` powers the benchmark. `barcelona_matches.csv` powers the tactical and opponent-focused charts.

2

Why Python

Keeping chart logic in Python lets the data preparation and the visualization layer stay in the same workflow and use the real processed datasets directly.

3

Story continuity

The page keeps the storytelling shell in HTML/CSS while delegating the heavy plotting work to Python-generated interactive charts.

4

Report use

Use screenshots from these final charts inside the implementation report and update the written explanation to match the real findings.
