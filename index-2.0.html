Act 1

Possession is not the same as control

Story function

This opening view creates tension. If Barcelona can lose despite overwhelming possession, the audience immediately needs an explanation for where that control breaks down. Swipe to see the detailed distribution.

Notice how losses still occur with high possession shares.
Boxplot: Distribution of possession rates across Match Outcomes.

Act 2

Control must become chances

Why this revision helps

It keeps the story coherent with the data currently prepared. The chart links possession, shot volume, and finishing efficiency, so the audience can see whether control turns into real attacking value.

The most useful seasons are the ones where possession, shot creation, and goal output rise together rather than moving in isolation.

Act 3

Which opponents actually shut Barcelona down?

Story function

After identifying a general tactical weakness, this view names the opponents who exploit it. That makes the story more actionable for coaching and preparation.

Lower goal output appears at the top because the heatmap is sorted by Barcelona’s average goals scored against each opponent.

Act 4

Where does Barcelona sit among Europe’s elite?

Story function

A benchmark works well as the closing panel because it turns the earlier diagnosis into context: is this a Barcelona problem, or a broader trait of top clubs?

Position represents the two main measures, while bubble size adds a compact signal for points per match.

Build notes

How the page is assembled

The visuals are generated in Python and embedded here as HTML charts. Rebuild them after changing the datasets by running `'/Applications/anaconda3/bin/python' build_visualizations.py`.

1

Data source

`master_matches.csv` powers the benchmark. `barcelona_matches.csv` powers the tactical and opponent-focused charts.

2

Why Python

Keeping chart logic in Python lets the data preparation and the visualization layer stay in the same workflow and use the real processed datasets directly.

3

Story continuity

The page keeps the storytelling shell in HTML/CSS while delegating the heavy plotting work to Python-generated interactive charts.

4

Report use

Use screenshots from these final charts inside the implementation report and update the written explanation to match the real findings.
